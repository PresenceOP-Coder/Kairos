# Contributing to Kairos

## How to run tests locally
Run tests using the Makefile:
`make test`

## Branch naming convention
Use descriptive branch names, e.g., `feat/add-latency-toxic`, `fix/proxy-leak`.

## Commit message convention
We follow Conventional Commits (e.g., `feat: add HTTP mutator`, `chore: update deps`).

## How PRs get reviewed
All PRs require passing CI checks and at least one review from a maintainer before merging.
